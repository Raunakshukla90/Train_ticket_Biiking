
# 🚆 Train Booking System

A simple and interactive Train Booking System built using **HTML, CSS, and JavaScript**. This project allows users to select their journey details, view available and occupied seats, choose seats, and calculate the total ticket price.

## 📌 Features

- **Journey Selection:** Select departure city, destination city, and travel date.
- **Travel Class Selection:** Choose between Sleeper (SL) and AC classes.
- **Interactive Seat Layout:**
